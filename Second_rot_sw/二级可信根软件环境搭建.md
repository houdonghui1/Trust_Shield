# 二级可信根软件环境搭建

## 一、安装依赖包

```bash
sudo apt-get upgrade
sudo apt-get install -y build-essential libtool automake libgmp-dev libnspr4-dev libnss3-dev openssl libssl-dev git acpica-tools libglib2.0-0 libglib2.0-dev libtasn1-6-dev tpm-tools libfuse-dev libsdl1.2-dev expect gawk socat libfdt-dev libseccomp-dev libgnutls28-dev expect flex bison ninja-build libjson-glib-dev libpixman-1-dev libsdl2-dev
```

## 二、安装 Python3 并编译 SeaBIOS

```bash
wget https://www.python.org/ftp/python/3.10.0/Python-3.10.0.tgz
tar zxf Python-3.10.0.tgz
./configure --enable-optimizations --with-ssl --prefix=/usr/local/python-3.10.0
sudo make -j
sudo make install
```

```bash
ln -s /usr/local/python-3.10.0/bin/python3.10 /usr/bin/python3
ln -s /usr/local/python-3.10.0/bin/pip3.10 /usr/bin/pip3
```

```bash
git clone https://git.seabios.org/seabios.git
```
> 如果 git 不下来可以在前面加代理网址：  
> `http://gh.301.ee/https://git.seabios.org/seabios.git`

修改 `Makefile` 文件将 `python` 改成 `python3`。

## 三、安装 libtpms

```bash
git clone https://github.com/stefanberger/libtpms
cd libtpms
./bootstrap.sh
./configure --prefix=/usr --with-openssl
sudo make -j
sudo make install
```

## 四、修改和安装 SWTPM

```bash
git clone https://github.com/stefanberger/swtpm 
cd swtpm/src/swtpm
patch mainloop.c mainloop_patch.patch   # 打入补丁
```

```bash
cd swtpm
./autogen.sh
./configure --prefix=/usr --with-openssl
sudo make -j
sudo make install
```

## 五、安装 QEMU

```bash
wget https://download.qemu.org/qemu-8.0.4.tar.xz
tar xf qemu-8.0.4.tar.xz
cd qemu-8.0.4
./configure --target-list=x86_64-softmmu --enable-kvm --enable-virtfs --enable-tpm --enable-sdl --audio-drv-list= --enable-uefi --with-ovmf=/usr/share/OVMF/OVMF.fd --prefix=/usr/local/qemu-x86_64
sudo make -j
sudo make install
```

## 六、下载 caliptra-sw

```bash
https://github.com/chipsalliance/caliptra-sw
```

把提供的 `setup_fpga.sh` 和 `caliptra_fpga.bin` 两个文件复制进 `caliptra-sw/hw/fpga` 路径下。

## 七、编译 caliptraROM.bin

```bash
cd caliptraRomC-2nd && make
```

把编译好的 `caliptraROM.bin` 放入 `test/caliptra_rom` 目录下即可。

## 八、启动虚拟机

```bash
cd test && ./start.sh qemu
```
