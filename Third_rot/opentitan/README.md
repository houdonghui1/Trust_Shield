# OpenTitan

![OpenTitan 标志](https://docs.opentitan.org/doc/opentitan-logo.png)

## 关于项目

[OpenTitan](https://opentitan.org) 是一个开源的硅级信任根（Root of Trust, RoT）项目。OpenTitan 将使硅级 RoT 的设计与实现更加透明、可信且安全，服务于企业、平台提供商和芯片制造商。OpenTitan 由 [lowRISC CIC](https://www.lowrisc.org) 管理，是一个协作项目，旨在产出高质量、可实例化为全功能产品的开放 IP。有关项目的更多信息，请参阅 [OpenTitan 网站](https://opentitan.org/) 和 [OpenTitan 文档](https://opentitan.org/book)。

## 关于本仓库

本仓库包含 OpenTitan 项目开发过程中编写的硬件、软件和实用工具。它采用单体仓库（monorepo）结构，即所有组件均存放在同一个仓库中。这种结构旨在促进 OpenTitan 项目参与合作伙伴之间的协作。
